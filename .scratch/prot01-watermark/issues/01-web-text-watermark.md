# PROT-01 web question and explanation watermark

## Problem

Authenticated practice questions and their revealed explanations do not carry a traceable account identifier in the web session.

## Solution

Add the authenticated owner UUID to the owner-scoped practice-session detail response. Render a faint tiled identifier over question and explanation text in the existing learner session route. Use a labelled session-ID fallback for older offline drafts. Keep the overlay decorative, pointer-transparent, and outside diagnostic images and anatomy.

## Acceptance Criteria

- The API returns the account ID only to the owner of that session.
- The learner-loop browser test sees the watermark on both question and revealed explanation text.
- The watermark is hidden from assistive technology and does not intercept controls.
- The session route adds no image overlays and makes no browser-capture-prevention claim.
- Generated TypeScript is regenerated by the existing GitHub Actions exporter; generated files are not edited by hand.
- Native platform capture protection and device-matrix acceptance remain separately tracked.

## Verification Seam

Use the existing practice-session detail HTTP integration seam and the connected learner-loop Playwright flow.
