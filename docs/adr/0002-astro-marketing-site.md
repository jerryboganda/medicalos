# Astro marketing site with honest, gated commerce

The public site is a static Astro app (`apps/site`) that shares the owner-locked §7.1 design tokens with the client and holds no learner data, calling only public or checkout API endpoints (§31.1). It deliberately ships no payment form: the billing API (COM-02) does not exist and §26.1 requires per-market payment rules before a paywall is built, so the pricing page presents the approved 7C tier vocabulary with prices marked "to be announced" and CTAs that route to the live app's free tier. App-link association files are emitted from one config module and make no claim until the first signed Tauri beta supplies real package identifiers and cert fingerprints. The site's own deployment origin is a pending owner decision, so no canonical `site` URL is set.
